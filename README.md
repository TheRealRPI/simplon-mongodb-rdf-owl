## 📋 Contexte
StreamVault mandate la structuration de son catalogue de films hétérogènes via MongoDB, puis la modélisation d'une ontologie cinéma OWL/RDF.

## 🗂️ Structure
```
MONGODB/
├── src/
│   └── livres.json          # Données source MongoDB
└── rendus/
    ├── MongoDB_Jalon01_Part01.md  # Partie 1 : MongoDB
    ├── OWL-RDF_Brief1_Partie2.md   # Partie 2 : Ontologie
    ├── cinema_paradiso.rdf        # Ontologie exportée
    ├── MongoDB, RDF, OWL.pdf      # Veille technologique
    └── screenshots/               # Captures d'écran
```
